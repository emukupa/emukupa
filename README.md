# Edward Manda

Software engineer and physicist in Oklahoma City. I teach programming by building one program
many times: the same task tracker in 12 languages, byte for byte identical, tested against one
contract.

### Beginner to Pro

**[beginner-to-pro](https://github.com/emukupa/beginner-to-pro):** a task tracker in Python,
C, C3, Zig, C++, Rust, Go, TypeScript, C#, Java, Kotlin and Swift. Five chapters per language
(concepts, one file, modules, done, undo), each with a start and end branch so you can code along.
Every language passes the same contract tests and a fuzz test against the Python version.
